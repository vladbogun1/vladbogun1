# Атлас петель: плоская крышка для утопленной кнопки 16 мм

Двадцать вариантов одной и той же откидной крышки для кнопки 16 мм, которая не выступает над панелью
(или выступает не больше чем на 1 мм). Рамка толщиной 1,8 мм клеится вокруг кнопки на двусторонний скотч
(3M VHB), сверху на ней лежит плоская крышка 1,4 мм. Общая толщина 3,3 мм, габарит 26 × 27 мм.
Ствол каждой петли Ø3,3 мм, вровень с крышкой и панелью. Крышка откидывается на 180° и ложится на панель.
Варианты различаются только петлёй.

## Что внутри

| Папка | Что там |
|---|---|
| `generator/` | Параметрический генератор на Python + [manifold3d](https://github.com/elalish/manifold): `common.py` (основание, крышка, раскладки петель), `variants.py` (20 петель), `build.py` (экспорт и проверка столкновений) |
| `site/` | 3D-просмотрщик (`index.html`, three.js): каждая модель на своей странице, анимация открытия, режим «на столе принтера», разрез |
| `site/models/vNN/print/` | **Готовые к печати STL**, уже повёрнутые в положение для печати |
| `site/models/vNN/*.stl` | Детали в собранном положении |
| `site/mesh/*.json` | Те же детали в компактном виде для просмотрщика |

## Семейства

- **A. Непечатная ось:** 01 филамент · 02 сталь · 03 пауза и закладка штифта · 04 винт M2
- **B. Печатные детали, собираются:** 05 штырьки на пружинящих стенках · 06 C-клипса · 07 конусы · 08 петля-ключ · 09 печатный D-штифт · 10 открытый крюк
- **C. Печать в сборе:** 11 конусный палец · 12 палец-капля · 13 печать в сборе и ось-филамент
- **D. Гибкие:** 14 живая петля · 15 многоленточная · 16 TPU-вставка · 17 ткань · 18 плёнка
- **E. Особые:** 19 магнитная · 20 подпружиненная

## Пересборка

```bash
pip install manifold3d numpy
cd generator && python3 build.py          # все 20
python3 build.py 1 14                     # только выбранные
```

`build.py` для каждого варианта поворачивает крышку с шагом 5° от 0 до 180° и считает объём пересечения с рамкой и панелью. Все 20 проходят с нулевым пересечением.

Главные размеры лежат в начале `generator/common.py`: высота кнопки над панелью `BTN_TOP`, толщина рамки `T`, окно под кнопку `HOLE_R`, толщина крышки `LID`, ширина `HW`. Если кнопка другая, поменяй их и пересобери.

## Посмотреть локально
